Five palette directions

Each block pairs the palette with a rough page mockup at the same scale, so the colors are judged the way a visitor would see them. Type pairings are suggestions, not locked in. Reply with a number, e.g. P3, or mix (“P2 base with P1’s accent”).

P1

Graphite & Signal

Dark, quiet, one loud accent. Reads as an engineering studio rather than an agency. The lime does all the pointing, so nothing else has to shout.
