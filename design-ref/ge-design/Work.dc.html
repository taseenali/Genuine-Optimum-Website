3D sports kit builder

A browser configurator for designing team kits on a live 3D model. Customers pick a base pattern, set colours per panel, add sponsor placements and player names, and rotate the garment to check it before ordering.

The output is not just a picture: each configuration exports as production-ready artwork with the correct panel separations, which removed the back-and-forth between the sales team and the print floor.
